# 退職日計算ナビ

退職日を入力すると、社会保険の資格喪失日ルール・有給消化・ボーナス支給日から
「最適退職日」と「最終出社日」を自動算出するスマホ向けWebツール。

- **本体**: `index.html` の1ファイルのみ（HTML/CSS/JS すべて内包）
- **外部依存ゼロ**: CDN・フォント・画像・API通信いっさいなし
- **完全ローカル処理**: 入力値はサーバーに送信されず、端末内だけで計算する

## ディレクトリ構成

```
taishokubi_navi/
├── index.html   ← これ1つで動く。ブラウザで開けばそのまま起動
└── README.md
```

ビルド不要・依存パッケージなし。`index.html` をそのまま静的ホスティングに置けば公開できる。

## 保守手順

### 1. 国民の祝日データの更新（年1回）

`index.html` 内の `/* HOLIDAYS:BEGIN */` 〜 `/* HOLIDAYS:END */` に囲まれた
`nationalHolidays` 配列に、新年度分を `"YYYY-MM-DD"` 形式で追記する。**それだけで更新完了**。

現在の収録範囲は **2026年〜2028年（全51件）**。2028年分を使い切る前に追記すること。

追記時の注意：

- **振替休日**（祝日が日曜と重なった場合の次の平日）を忘れず入れる
- **国民の休日**（祝日に挟まれた平日。主に9月の敬老の日と秋分の日の間）も入れる
- 春分の日・秋分の日は前年2月の官報（国立天文台「暦要項」）で確定する。
  暫定値を入れている場合は、確定後に差し替える

出典: [内閣府「国民の祝日について」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)

### 2. 社会保険料率の改定時

`index.html` 冒頭の定数を直すだけ。計算式には手を入れなくてよい。

| 定数 | 現在値 | 内容 |
|---|---|---|
| `HEALTH_RATE` | `0.100` | 健康保険料率（協会けんぽ全国平均。都道府県により9.35%〜10.5%程度） |
| `CARE_RATE` | `0.0159` | 介護保険料率（40歳以上65歳未満に上乗せ） |
| `PENSION_RATE` | `0.183` | 厚生年金保険料率（全国一律・平成29年9月以降固定） |
| `PENSION_MIN` | `88000` | 厚生年金の標準報酬月額の下限 |
| `PENSION_MAX` | `650000` | 厚生年金の標準報酬月額の上限 |
| `BONUS_ESTIMATE` | `300000` | 賞与の推定獲得額の目安 |
| `NOTICE_MONTHS` | `1` | 上司への申し出目安（か月前） |

協会けんぽの料率は例年**3月分（4月納付分）から改定**される。

### 3. 標準報酬月額の等級表の改定時

`/* GRADES:BEGIN */` 〜 `/* GRADES:END */` の `STANDARD_GRADES` 配列を差し替える。
形式は `[健保等級, 標準報酬月額, 報酬月額の下限(以上), 報酬月額の上限(未満)]`。
最上位等級の上限は `null`。現在は協会けんぽの現行50等級を収録。

## デプロイ

静的ファイル1枚なので、任意の静的ホスティングに置くだけ。

### Cloudflare Pages（推奨）

1. このリポジトリをGitHubにpush
2. Cloudflare ダッシュボード → Workers & Pages → 「Pagesプロジェクトを作成」
3. GitHubリポジトリを連携
4. ビルド設定は**すべて空のまま**にする
   - フレームワークプリセット: `なし`
   - ビルドコマンド: 空
   - ビルド出力ディレクトリ: `/`
5. 「保存してデプロイ」

以降、GitHubにpushするたび自動で再デプロイされる。

### 公開後にやること

- `index.html` の OGP に `og:url` と `og:image` を追加する（現在は未設定）
- Google Search Console にサイトを登録し、インデックス登録をリクエストする
- 独自ドメインを使う場合は Cloudflare Pages の「カスタムドメイン」から設定する

## 動作確認

`index.html` をブラウザで開き、以下を確認する。

| シナリオ | 入力 | 期待する結果 |
|---|---|---|
| ボーナスまたぎ | 退職 2026-09-15 / 賞与 2026-12-10 / 月給 300,000 | 最適日 2026-12-31、赤い警告バナー、お得度 +342,450円 |
| 既に月末 | 退職 2026-03-31 | 社保節減 ±0円、比較欄が「変更なし」表示 |
| 空白期間 | 上記 ＋ 入社 2026-04-15 | 「約14日間の空白期間が発生」の警告 |
| 即時移行 | 退職 2026-03-31 ＋ 入社 2026-04-01 | 「社会保険の空白期間なし（即時移行）」の緑バナー |
| 祝日の反映 | 退職 2026-05-12 / 有休4 / 引継0 | 祝日ON → 最終出社 5/1、祝日OFF → 5/6 |
| 等級判定 | 月給 350,000 | 標準報酬月額 360,000円（健保25等級）／本人負担 50,940円 |

> `file://` で直接開いた場合、ブラウザの制限でクリップボードAPIが拒否される。
> その場合はテンプレ文面が自動選択されるフォールバックが動く。
> **https で配信すればワンタップコピーが正常動作する。**
